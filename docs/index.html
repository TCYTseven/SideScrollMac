SideScroll

A scrolling window manager for macOS. Windows sit side by side on one endless strip instead of being squeezed into a grid. Free and open source.

Click the screen and press the real shortcuts (hold ⌃⌥, or just the letter keys here), swipe sideways with two fingers, or use the buttons.

What it does

  • Three- or four-finger trackpad swipe moves along the strip, with momentum and snapping.
  • Width presets, wider / narrower, full width and centering, one key each.
  • Stack windows into a column, flip it to tabs, pin a column to a screen edge.
  • Dialogs and fixed-size windows float automatically; per-app rules for the rest.
  • One strip per display and per Space. Column order survives restarts.
  • Every shortcut can be rebound. Needs only the Accessibility permission.
macOS 13 or newer, Apple silicon and Intel. MIT licensed.

# Raycast script commands

In Raycast: Settings → Extensions → Script Commands → Add Directories, and pick this folder. Each script sends a `sidescroll://` URL to the running app, so they work with any shortcut you assign in Raycast.

The same commands work from Terminal with the `sidescroll` tool (Settings → General → Install Command-Line Tool), for example `sidescroll focus-left`. Run `sidescroll --list` for every command.
